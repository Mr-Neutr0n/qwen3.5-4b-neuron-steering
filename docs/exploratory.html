Two-neuron steering in Qwen3.5-4B

A reproduction across 50 prompts. The recipe changes safety responses, ordinary advice, and basic task performance.

This is not an abliterated model. It uses the same model weights with a simple runtime hook. The hook changes activations during inference; it does not edit the weights or train a new checkpoint.

We ran original Qwen3.5-4B and a two-neuron intervention on identical prompts. We also tested each neuron alone, half strength, and reversed signs on six fixed prompts. The weights stayed unchanged.

05

What changed inside the model

A neuron here holds a signed scalar value. It is not an on/off switch or a readable thought. We add a fixed, calibrated offset before the MLP down projection at every prompt and generated token.

The intervention

activation += dose × residual_median / column_norm

Recipe doses are L14 N8949 +1 and L13 N7956 −1. Indices are zero-based. A negative dose subtracts a value. It does not switch a neuron off.

The earlier layer 13 intervention can change layer 14's input before layer 14 receives its own addition. The two effects need not add up cleanly.

Each full-dose addition contributes a projection vector with a norm equal to the calibrated median residual norm for that layer, before rounding. These are substantial interventions. A change in only two scalar positions does not imply a small numerical disturbance.

Still untested
